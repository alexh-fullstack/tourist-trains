# Витрина туристских поездов

Одностраничный веб-прототип каталога туристических поездов (React 19, TypeScript, Tailwind CSS v4, Vite).

## 🚀 Как запустить локально
```bash
npm install && npm run dev   # Запуск локально (http://localhost:5173)
npm test                     # Запуск 27 автоматических тестов (Vitest + RTL)
npm run build                # Сборка продакшн-бандла
```

## 💡 Принятые решения и почему
- **React 19 + TypeScript + Vite**: строгая типизация схемы JSON, предсказуемость состояния и мгновенный билд.
- **Tailwind CSS v4 + Lucide**: строгий корпоративный стиль, светлая/тёмная тема, адаптивность (mobile-first) и режим для слабовидящих.
- **UX & Доступность**: интерактивный календарь выездов, двуязычность (RU/EN), URL-синхронизация фильтров и ARIA-разметка.
