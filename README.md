# Витрина туристских поездов

Одностраничный веб-прототип каталога туристических поездов (React 19, TypeScript, Tailwind CSS v4, Vite).

## 🚀 Как запустить локально
```bash
npm install && npm run dev   # Локальный запуск (http://localhost:5173)
npm test                     # Запуск 27 автоматических тестов (Vitest + RTL)
npm run build                # Сборка продакшн-бандла
```

## 💡 Принятые решения и почему
- **Конверсия и простота выбора**: календарный выбор дат отправления и мгновенный поиск помогают клиенту быстрее подобрать тур и повышают конверсию в покупку билета.
- **UI/UX и доступность (A11y)**: корпоративный стиль, светлая/тёмная тема, mobile-first адаптивность и режим для слабовидящих расширяют охват аудитории.
- **Локализация (RU/EN) и шеринг**: поддержка двух языков привлекает иностранных туристов, а сохранение фильтров в URL позволяет легко делиться ссылкой на найденный тур.

## 🔮 Что можно улучшить
- Интерактивную карту маршрутов с остановками для наглядной визуализации путешествия.

- Офлайн-режим (PWA) для доступа к билетам и программе экскурсий в поездке без интернета.
