# Витрина туристских поездов

Веб-прототип каталога туристических железнодорожных маршрутов с фильтрацией, поиском и детальным просмотром туров.

## 🚀 Как запустить локально
```bash
npm install && npm run dev   # Установка и запуск (http://localhost:5173)
npm test                     # Запуск 26 автоматических тестов (Vitest + RTL)
npm run build                # Сборка продакшн-бандла
```

## 💡 Принятые решения и обоснование
- **React 19 + TypeScript + Vite**: Обеспечивают строгую типизацию данных (`Train`, `FilterState`), мгновенный HMR и быстрый production-билд.
- **Tailwind CSS v4 + Lucide Icons**: Лаконичный корпоративный UI, чистая тёмная/светлая тема, режим для слабовидящих и mobile-first адаптивность.
- **Двуязычность (RU/EN) и синхронизация с URL**: Полная локализация интерфейса и данных туров с сохранением параметров фильтров в строке адреса для удобного шаринга.
