# 🚂 Витрина туристских поездов

Одностраничный веб-прототип каталога туристических поездов России с фильтрацией, поиском, адаптивной вёрсткой и модальным окном деталей тура.

## 🚀 Как запустить локально
```bash
npm install       # Установка зависимостей
npm run dev       # Запуск локального сервера разработки (http://localhost:5173)
npm test          # Запуск автоматизированных тестов (Vitest + React Testing Library)
npm run build     # Сборка production-бандла (tsc + vite build)
```

## 💡 Принятые архитектурные и технические решения
1. **React 19 + TypeScript + Vite**: Обеспечивают строгую типизацию данных (`Train`, `FilterState`), мгновенный HMR и быстрый production-билд.
2. **Tailwind CSS v4 + Lucide Icons**: Лаконичный современный UI в эстетике ж/д круизов, mobile-first адаптивность, доступные цветовые акценты и плавные анимации.
3. **URL State Synchronization**: Состояние фильтрации (поиск, регион, месяц, сортировка, открытый поезд) автоматически синхронизируется с `window.location.search`, позволяя делиться прямыми ссылками на отфильтрованные подборки и конкретные поезда.
4. **Удобный UX & Доступность (a11y)**: Модальное окно управляется с клавиатуры (клавиша `Esc`, клик вне окна, фокус-трап), внешняя ссылка `buy_url` безопасно открывается в новой вкладке (`target="_blank" rel="noopener noreferrer"`).
5. **Полное покрытие тестами**: 23 теста (unit и integration) проверяют форматирование дат/валюты, логику фильтрации, поиск, открытие модалок и сброс фильтров.
