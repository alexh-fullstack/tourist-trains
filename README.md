# Витрина туристских поездов

Одностраничный веб-прототип каталога туристических поездов (React 19, TypeScript, Tailwind CSS v4, Vite).

## 🚀 Как запустить локально
```bash
npm install && npm run dev   # Локальный запуск (http://localhost:5173)
npm test                     # Запуск 27 автоматических тестов (Vitest + RTL)
npm run build                # Сборка продакшн-бандла
```

## 💡 Принятые решения и почему
- **Конверсия и простота выбора**: календарный выбор дат отправления и мгновенный поиск помогают клиенту быстрее подобрать тур и повышают конверсию в покупку билета.
- **UI/UX, доступность и темы**: корпоративный стиль, переключение светлой/тёмной темы, mobile-first адаптивность и режим для слабовидящих (A11y) расширяют охват аудитории.
- **Локализация (RU/EN)**: поддержка двух языков открывает сервис для иностранных туристов и англоязычных пользователей.
- **Синхронизация с URL**: сохранение фильтров и параметров поиска в адресной строке позволяет клиентам легко делиться прямой ссылкой на найденный тур.

## 🔮 Что можно улучшить
