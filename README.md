# Витрина туристских поездов

Одностраничный веб-прототип каталога туристических поездов (React 19, TypeScript, Tailwind CSS v4, Vite).

## 🚀 Как запустить локально
```bash
npm install && npm run dev   # Локальный запуск (http://localhost:5173)
npm test                     # Запуск 27 автоматических тестов (Vitest + RTL)
npm run build                # Сборка продакшн-бандла
```

## 💡 Принятые решения и почему
- **React 19 + TypeScript**: выбран для строгой типизации JSON-данных туров на этапе компиляции, что исключает ошибки рендера при неполных данных.
- **Vite + Tailwind CSS v4**: обеспечивает мгновенную сборку и адаптивный корпоративный UI без тяжелых библиотек со встроенной тёмной темой и режимом A11y.
- **Календарь дат и синхронизация с URL**: календарный выбор дат отправления удобнее плоского списка, а сохранение фильтров в URL позволяет делиться ссылкой на тур.
